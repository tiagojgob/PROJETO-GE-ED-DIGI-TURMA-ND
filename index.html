R5 - Introdução ao CSS e estilização

O que é CSS?

CSS (que significa Cascading Style Sheets, ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a aparência, o design e o layout de uma página web.

Vamos utilizar novamente o ambiente de programação: VS Code on-line

O VS Code (Visual Studio Code) é um editor de código-fonte gratuito, leve e de código aberto desenvolvido pela Microsoft, que permite a escrita e a edição de programas em diversas linguagens de forma prática.
